# B8A1: Problem Solving with TypeScript & OOP

## Overview

This repository contains my solutions for Assignment B8A1. It covers the core TypeScript concepts from Modules 1, 2 and 3:

- Basic types and optional parameters
- Union types and type narrowing with `typeof`
- Readonly tuples
- Generics with rest parameters and `keyof` constraints
- Interfaces
- OOP with classes, inheritance and access modifiers (`protected`, `private`)
- Promises with `async` behaviour and error handling
